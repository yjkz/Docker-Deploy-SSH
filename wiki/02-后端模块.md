# 02 — 后端模块(Rust)

后端共 8 个源文件(不含 main.rs),约 7,560 行。分层原则:**commands.rs 是唯一编排层**,其余模块是可独立单测的纯逻辑或 I/O 封装。

全局约定:

- 命令统一返回 `Result<T, String>`,错误信息中文带上下文
- 非测试代码禁止 `unwrap()`/`expect()`(唯一豁免:`config.rs` 的 `current_exe().expect`,签名固定为返回 PathBuf 所致)
- 所有跨前后端结构体 derive `Serialize`(+按需 `Deserialize`/`Clone`),字段 snake_case(serde 未设 rename_all,前端必须用 snake_case 读字段)
- 子进程一律参数数组不经 shell;SSH 远端命令一律经 `shell_single_quote` 单引号转义

Builder 组装:`.manage(DeployState::default())` → `.invoke_handler(generate_handler![19 个命令])` → 日志插件初始化(文件 target 无条件,Stdout 仅 `cfg!(debug_assertions)`,原因:release 是 GUI 子系统进程,无 stdout 句柄,fern 写失败会 panic)。

## docker.rs(575 行)— Docker CLI 封装

所有 Docker 操作走 `std::process::Command` 调 `docker` CLI,统一入口 `new_command()`(Windows 下加 `CREATE_NO_WINDOW 0x0800_0000`,防 GUI 进程闪黑框)。

| 接口 | 说明 |
|---|---|
| `check_host() -> HostCheckReport` | 宿主机检测:`docker_installed`(`docker --version`)、`daemon_running`(`docker info`)、`compose_ok`、`docker_version`、`arch`、`disk_free_gb: Option<f64>`(fs4 查临时目录盘,失败 None)、`error` |
| `start_daemon() -> Result<(),String>` | 已运行早返回 → `Start-Service com.docker.service`(失败不致命)→ 启动 Docker Desktop.exe → 轮询 `docker info` 至多 60s |
| `list_images() -> Vec<ImageInfo>` | `docker images --format {{json .}}` 逐行解析;坏行 warn 跳过 |
| `ImageInfo { repository, tag, size_bytes, created, id }` | size_bytes 为 1024 进制换算(`size_to_bytes`,与 docker SI 千进制有已知少量偏差) |
| `tag_image(image, new_tag)` / `image_exists(image) -> bool` / `image_size(image) -> Option<u64>` | `docker tag` / `docker image inspect` 退出码 / `--format {{.Size}}` |
| `make_deploy_tag(repository, _tag) -> String` | `repo:%Y%m%d-%H%MSS`(chrono Local;同秒撞名由 commands 层 unique_deploy_tag 兜底) |
| `save_gzip(image, out_path, progress_cb: impl Fn(u64)) -> Result<u64,String>` | `docker save` stdout → 64KB 循环读 → flate2 GzEncoder → 文件;progress_cb=已写压缩字节(结束补发一次=总大小);错误路径 kill 子进程+删半成品;`ErrorKind::Interrupted` 重试 |

## ssh.rs(738 行)— SSH/SFTP 客户端与服务器检测

- `pub const INSTALL_DOCKER_CMD: &str = "curl -fsSL https://get.docker.com | sh";`
- `SshClient::connect(cfg, password_plain: Option<&str>)`:Key 类型 `load_secret_key(key_path, None)`(**仅未加密 PEM**);Password 用传入明文;`check_server_key` 无条件接受(有意取舍,见 07)
- `exec(cmd, on_output: &mut impl FnMut(&str)) -> Result<i32,String>`:消息循环到 Close 才返回(不丢输出尾);stdout+stderr 合并按行回调;非 UTF-8 lossy
- `sftp_upload(local, remote_dir, remote_name, on_progress, resume: bool)`:64KB 块,回调(已传/总数);远端句柄显式 shutdown;**resume=true 时断点续传**(stat 远端半成品 → `resume_plan` 决策:远端更小→无 TRUNCATE+双端 seek 续写;远端≥本地→AlreadyDone 直接成功),调用点:镜像包 true / 文件映射 false
- `sftp_stat_size(remote_path) -> Option<u64>`:远端文件大小(NoSuchFile→None)
- `resume_plan(remote, local, resume) -> ResumePlan`:续传决策纯函数(Fresh/Resume(offset)/AlreadyDone)
- `sftp_upload_dir(local_dir, remote_dir, ...)`:递归(不跟随 symlink),mkdir -p,远端路径一律 `join_remote` 用 `/` 拼接
- `check_server_env(client, remote_dir) -> ServerCheckReport { docker, compose, gzip, remote_dir_exists, disk_free_gb, errors }`:五个探测命令(df 用 `df -PBG`,BusyBox 不兼容已知)
- `mkdir_p_cmd(path)` / `shell_single_quote(s)` / `join_remote(base, rel)` / `normalize_remote(dir)`:命令拼装与路径工具(单引号 `'\''` 转义,有单测)

## 模块依赖关系

```
lib.rs ──▶ commands.rs ──┬─▶ config.rs(配置实体;无内部依赖)
                         ├─▶ docker.rs(本机 Docker;仅标准库+flate2/chrono/fs4)
                         ├─▶ ssh.rs(SSH/SFTP;依赖 config::ServerConfig)
                         ├─▶ crypto.rs(DPAPI;无内部依赖)
                         ├─▶ stack.rs(compose 解析;依赖 config::TransferMode/ServiceOverride)
                         └─▶ history.rs(部署历史;复用 config 的原子写与目录)

另:lib.rs 注册 tauri-plugin-dialog(文件浏览对话框,前端经 __TAURI__.dialog 调用,无自定义命令)
```

`stack.rs`、`docker.rs`、`crypto.rs` 的核心函数是纯函数或单参 I/O,**单测不依赖 Docker/网络**;真机行为测试标 `#[ignore]`(7 个),`cargo test -- --ignored` 单独跑。
