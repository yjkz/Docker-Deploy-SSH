# 04 — 契约参考(命令 / 事件 / 配置 Schema)

前后端之间的全部接口。**改动任何一侧必须同步本文档与另一侧。**

命名规则:

- invoke 参数名:JS 侧 **camelCase**(Tauri 2 自动映射 Rust snake_case 形参)
- 对象字段(请求体与返回值/事件载荷):一律 **snake_case**(serde 无 rename_all)
- 枚举字符串:`"Key"/"Password"`、`"Local"/"Pull"`、`"Exact"/"RepoOnly"/"Missing"`
- 远程管理模块上游约定:`docker --format json` 的输出是 **NDJSON 且字段 PascalCase**(ID 字段全大写 `ID`),由 Rust 结构体(`#[serde(rename_all = "PascalCase")]` + `#[serde(rename = "ID")]`)解析后**转为 snake_case 再返回前端**;前端永远只见 snake_case

### 远程管理 — 实时监控(manage_stats.rs,2 个)

| 命令 | 参数 | 返回 | 说明 |
|---|---|---|---|
| `manage_stats_start` | `{ serverId, passwordPlain?, intervalSecs? }` | `null`(同步) | 启动 `docker stats --no-stream --format json` 轮询(默认 2s,clamp 1-60s);数据经 `manage-stats` 事件流式推送,**命令本身不返回数据**。旧版 Docker 不认 `--format json` 简写时自动降级 `'{{json .}}'` 模板(进程级一次性降级) |
| `manage_stats_stop` | — | `null` | 停止当前会话(幂等;后端已自停时仍返回 Ok) |

会话语义:**全局单会话**(再次 start 自动替换旧会话,generation 代号机制);一条 SSH 连接跨轮复用(传输层失败立即重连一次,连续 3 轮连接失败或权限拒绝自动停止,以 payload `stopped: true` 通知)。

### 远程管理 — 交互终端(manage_exec.rs,4 个 + ssh.rs `exec_interactive`)

| 命令 | 参数 | 返回 | 说明 |
|---|---|---|---|
| `manage_exec_start` | `{ serverId, passwordPlain?, containerId, shell? }` | `ExecStartInfo` | 打开 PTY 通道执行 `docker exec -it <c> <shell>`,返回 `session_id` + **实际使用的 shell**(前端选「自动」时=探测结果,以此回显)。shell 探测:同连接先非交互 `docker exec` 验证 bash/sh **存在且可执行**(`command -v` + `bash -c true`),distroless(无 sh)直接报错 |
| `manage_exec_write` | `{ sessionId, data }` | `null` | 向 stdin 写入(含回车 `\r`) |
| `manage_exec_resize` | `{ sessionId, cols, rows }` | `null` | 转发 SSH `window_change`(前端行式终端未接线,保留) |
| `manage_exec_stop` | `{ sessionId }` | `null` | 关闭通道并清理会话;会话不存在 → Err |

输出经 `manage-exec-output` 事件异步推送(见下);会话结束(eof=true)后端自清理会话。**shell 显式指定时尊重其值**,探测失败(容器未运行等)在开终端前报错。

## 2. 事件(6 个)

| 事件 | 载荷 | 说明 |
|---|---|---|
| `deploy-progress` | `{ step: number, total: number, message: string }` | 单镜像 total=5(打标签/导出压缩/上传镜像/同步文件/服务器部署);整栈 total=6(分类确认/打包/上传/装载/拉取/启动);step 从 1 开始,只在步骤**开始**时发 |
| `deploy-log` | `string` | 一行日志,带 `[HH:MM:SS]` 前缀 |
| `deploy-done` | `{ success: boolean, message: string }` | **任何路径恰好一次**;取消固定 `message === "部署已取消"`(前端据此显示黄条) |
| `server-log` | `string` | install_server_docker 的逐行输出 |
| `manage-stats` | `{ server_id: string, stats: StatsRow[], error: string\|null, stopped: boolean }` | 监控数据流,每轮一条;`error` 为单轮失败中文提示(成功轮 null);**`stopped=true` 表示后端监控循环已自行终止**(权限拒绝/连续 3 轮连接失败),前端据此置回「已停止」,普通单轮失败为 false(循环继续,仅提示) |
| `manage-exec-output` | `{ session_id: string, data: string, eof: boolean, error: string\|null }` | 终端输出流;`data` 为本次输出文本(lossy UTF-8);**eof=true 表示通道已关闭**(error 携带结束原因:用户主动停止为 null / 远端退出码(127/126 有针对性提示+输出尾段 OCI 原文)/ 写失败 / SSH 通道关闭),前端据此提示并停用输入 |

```jsonc
// StatsRow(manage-stats 的 stats 元素;数值均为 docker stats 原样字符串)
{ "container_id": "string", "name": "string", "cpu_percent": "0.12%",
  "mem_usage": "56.2MiB / 1.944GiB", "mem_percent": "2.82%",
  "net_io": "1.2kB / 3.4kB", "block_io": "8.19MB / 0B", "pids": "5" }
```

`deploy` / `deploy_stack` 同步返回 null 不代表成功;成功/失败仅以 `deploy-done` 为准。
监控/终端是事件驱动:`manage_stats_start` / `manage_exec_start` 同步返回不代表有数据/已连上;数据只经事件。

## 4. 全局错误约定

- 所有命令 `Result<T, String>`,错误信息**中文带上下文**
- Promise reject 的字符串直接 toast/错误框展示,不再加工
- 取消统一文案 `"部署已取消"`;SSH 超时 `"连接超时(15 秒):…"` / 命令超时按常量名区分
- `deploy-done` 失败 message 为中文错误(含失败环节上下文);日志另有 `部署失败: <原因>` 行
- **远程管理权限兜底**:非 root 用户无 docker.sock 权限时,统一返回固定文案「当前 SSH 用户无 Docker 权限(无法访问 /var/run/docker.sock),请将该用户加入 docker 组或使用 root 用户连接」(manage.rs `PERM_DENIED_MSG`,各命令与监控流共用)
- 远程管理超时梯度:建连 15s / 常规 exec 60s / 镜像 pull 300s / 栈 up-down 120s;错误形如 `<动作>超时(60 秒):<提示>`

## 5. 变更流程清单(改契约时)

1. 改 Rust struct/命令 → `cargo test` 全绿
2. 改对应 JS 调用与字段读取 → `node --check` + id 引用核对
3. 更新本文档对应表格
4. 跑 `npm run tauri build` 冒烟 + 至少一次真实页面操作
5. 远程管理新增命令:同时核对 `lib.rs` generate_handler 注册、manage 页 Tab 路由(switchTab)、自动刷新路径(refreshAll)与离页清理(onLeave)
