# 03 — 前端说明(ui/)

原生 HTML/CSS/JS,**无框架、无打包器、无 npm 运行时依赖**。`ui/` 目录即 Tauri 的 frontendDist,构建时整体内嵌进 exe。通过 `window.__TAURI__.core.invoke` 调后端(因 tauri.conf.json 设了 `app.withGlobalTauri: true`)。

## 页面结构(index.html,852 行)

单页应用:左侧黑色 dock 导航(6 项:`01 环境检测 / 02 镜像列表 / 03 服务器管理 / 04 部署向导 / 05 远程管理 / 06 回滚中心`)+ dock 末端**设置齿轮按钮**(`#settings-entry-btn`,阶段四)+ 亮暗主题切换按钮 + 6 个 `<section data-page>`。默认显示检测页。02/04 受环境闸门锁定;03/05/06 只做远程 SSH 操作/配置编辑,始终可进入。body 末尾另有:全站帮助悬浮按钮 `#help-fab` + 帮助模态 `#help-modal`、servers-modal、manage-modal(远程管理共用模态)、**notify-modal(通知中心)**、**config-io-modal(配置中心)**、**settings-modal(设置中心)**、**deploy-modal(部署详情 + 一键回滚,共用)**、**deploy-batch-modal(批量部署服务器多选)**、**migrate-project-modal(项目迁移,04 页)**、**cleanup-modal(清理分析,03 页)**。04 页内另有部署页常驻元素:`#deploy-batch-btn` 入口按钮、`#deploy-resume-banner` 断点续传横幅、`#deploy-batch-panel` 批量状态面板。06 页内:`#rollback-server-select` / `#rollback-scan-root` / `#rollback-projects` / `#rollback-detail` / `#rollback-log`。窄窗口(<900px)dock 转顶部横向黑条。

> 注:早期文档写的 `deploy-rollback-modal` 并不存在,回滚界面一直复用 `#deploy-modal`(第三批起 06 页提供独立入口)。

## JS 模块与全局约定

加载顺序:`app.js → check.js → images.js → servers.js → deploy.js → manage.js → rollback.js → notify.js → help.js → config-io.js → settings.js`(普通 script,无模块系统)。

### app.js(680+ 行)— 全局基础设施

| `toast(msg, type)` | 右下角墨底纸白条,2.5s 自动消失;**SR 播报(pass 4)**:ok/info → `role="status"`(polite)、warn/fail → `role="alert"`(断言),不抢焦点 |

### check.js(396 行)— 01 环境检测页

- **部署历史**(折叠面板):`get_history` 渲染(时间 / 模式徽章 / 项目@服务器 / 镜像截断 / 结果徽章 / 耗时 / **操作列:回滚按钮(阶段一)**;rollback 记录灰 — 防回滚链),最新在前,上限 50 条;pagechange + deploy-done 双触发刷新
- **一键回滚模态**(阶段一):列表/确认/执行三视图(详见 deploy.js 小节);执行期模态内日志镜像 deploy-log,主页日志同步追加;模态执行中禁关(关闭钮/Esc/遮罩三处同步拦截)
- 失败提示走全表单统一的强化通道(见 servers.js 小节)
