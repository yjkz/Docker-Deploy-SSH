# 03 — 前端说明(ui/)

原生 HTML/CSS/JS,**无框架、无打包器、无 npm 运行时依赖**。`ui/` 目录即 Tauri 的 frontendDist,构建时整体内嵌进 exe。通过 `window.__TAURI__.core.invoke` 调后端(因 tauri.conf.json 设了 `app.withGlobalTauri: true`)。

## 页面结构(index.html,639 行)

单页应用:左侧黑色 dock 导航(5 项:`01 环境检测 / 02 镜像列表 / 03 服务器管理 / 04 部署向导 / 05 远程管理`)+ 5 个 `<section data-page>` + 末端亮暗主题切换按钮。默认显示检测页。02/04 受环境闸门锁定;03/05 只做远程 SSH 操作/配置编辑,始终可进入。body 末尾另有:全站帮助悬浮按钮 `#help-fab` + 帮助模态 `#help-modal`、servers-modal、manage-modal(远程管理共用模态)。窄窗口(<900px)dock 转顶部横向黑条。

## JS 模块与全局约定

加载顺序:`app.js → check.js → images.js → servers.js → deploy.js → manage.js → help.js`(普通 script,无模块系统)。

### app.js(300 行)— 全局基础设施

| 成员 | 说明 |
|---|---|
| `window.showPage(name)` | 切换 section;`LOCKED_PAGES = ['images','deploy']` 在 `AppState.hostOk=false` 时拦截并灰置导航(截获后**不派发** pagechange);切页成功后 `window.dispatchEvent(new CustomEvent('pagechange', { detail: { page: name } }))`(监听方从 `e.detail.page` 取页名);新 section 触发 clip-path 揭示动画 |
| `window.AppState` | `{ hostOk: bool }`,读写镜像到 `localStorage['dd_hostOk']`(defineProperty 拦截) |
| `window.AppBus` | `{ invoke(cmd,args), on(event,cb), pickPath({directory,filters,title}) }`——invoke/listen/对话框的封装,带 `__TAURI__` 缺失防护;**前端一律经 AppBus 调用** |
| `toast(msg, type)` | 右下角墨底纸白条,2.5s 自动消失 |
| `copyText(text)` | clipboard API + execCommand 回退 |

## 设计语言(ark,style.css 2,416 行)

黑白青工业信息系统(ark-ui 契约,Family=ark / Depth=complex,`index.html` 根元素 `data-ark-theme="ark" data-ark-depth="complex" data-ark-scheme="light|dark"`)。重构简报见 `docs/ui-redesign-brief-ark-light.md`,实施要点:

- **Tokens**(:root):`--ark-ink #080a0b`(墨)/ `--ark-paper #f4f6f6`(纸白主表面)/ `--ark-signal #18d1ff`(青,仅状态/激活/主操作)/ `--ark-signal-dim` / `--ark-ok #c8eb21`(仅成功徽章底)/ `--ark-warn #ffd23f`;radius 0;双色纪律(不用红,失败=墨底白字)
- **字体三角色栈**(v4.5 后自捆绑,`ui/fonts/` woff2 ×8 + OFL 许可 ×3,`font-display: swap`):
  - `--font-cond`:Space Grotesk 500/700 — 页面编号/英文微标签(大写 + 字间距 .08–.18em)
  - `--font-mono`:JetBrains Mono 400/500 — ID/端口/日志/终端等宽 + tabular-nums;**日志/终端/code 区域 `font-variant-ligatures: none`**(连字会让逐字符解析/复制失真)
  - `--font-cjk`:Noto Sans SC 400/500/600/700 — 正文(CJK 不写 unicode-range,按需子集)
- **状态文本 token**(scheme 感知,替代裸色值,过 AA 对比):`--ark-stat-warm`(预警文字,亮=暗琥珀 `#7a5f00`/暗=琥珀 `#ffd23f`)、`--ark-stat-hot`(过热文字,亮=暗红 `#9c3400`/暗=柔和红)、`--ark-warn-text`(琥珀系警示文字,纸面上替代裸 `#ffd23f`——其在纸面 ≈1.4:1 不可读)
- **终端恒暗面板 token**:`--ark-terminal-bg`(日志/终端面板底,**两主题恒暗**,暗色下 `#0d1113` 略浮于舞台)+ `--ark-terminal-fg`(恒浅色文字)——全页唯一允许的深色块族
- **命中区约定**:主题切换按钮 40×40 命中区(可见仅 16px 图标);表格小按钮经 `::after` 不可见扩展 `inset: -9px -2px`(视觉零位移,竖向命中 42px ≈ 行高 44px;已知取舍:极窄窗口按钮折行时盖上一行按钮底 5px 边带)
- **徽章三态**:`.badge-ok`(signal-dim 底)/`.badge-warn`(琥珀底)/`.badge-fail`(ink 底白字),配内联 SVG symbol(✓/×/▸,`<use>` 引用)——**禁 emoji、禁新增颜色字面量(只用 var(--ark-*))**
- **模态体系**:`.modal-overlay/.modal-card` 共用;sizes:`.modal-terminal`(终端,宽 min(1000px,94vw) + 60vh 输出区)、`.modal-wide`(查看类弹窗放大:容器/栈日志、栈服务状态、卷/网络 inspect,正文 65vh 滚动)——manage.js 经 body 标记类(`manage-terminal-modal`/`manage-wide-modal`)互斥切换
- **审计(audit)**:用 ark-ui skill 自带审计脚本(`skills/ark-ui-skill/scripts/audit-ark-ui.mjs`)做设计契约审查,修复以 style.css 内「审计修复追加块」注释落位(P1 命中区/对比度、P2 focus-visible/滚动条主题/modal-wide 等),注释保留裁决理由
- **动效**:切页 clip-path reveal 300ms;部署进行中节点 pulse 1.8s;`@media (prefers-reduced-motion: reduce)` 全归零;`@media (max-width:900px)` dock 转横向条
- **防 XSS 纪律**:所有动态数据 `createElement`/`textContent`,innerHTML 仅限 manage.js 模态静态骨架与 help.js 静态章节(不含用户数据);用户数据一律 `escHtml`(textContent→innerHTML)或纯 text 节点

## 前端硬约束(改动前必读)

1. 所有 invoke/事件字段 **snake_case**(见 [04-契约参考.md](04-契约参考.md)),invoke 参数名本身 camelCase
2. `document.getElementById` 的每个 id 必须在 index.html 存在(动态 id 模式:`check-*`、`deploy-step-1..6`、`srvf-*`、`prjf-*`)
3. 部署进行中不得再次发起 deploy(后端全局单取消标志,二次 deploy 会重置它)
4. 保存配置一律"新鲜 get_config → 就地改字段 → 全量写回",禁止用旧快照整对象替换
5. 事件监听用模块级守卫保证单次注册;**监控/终端先订阅事件再 invoke**,unlisten 必须成对清理
6. 不引框架/打包器;不新增颜色字面量;不引入 emoji 图标

## 亮暗双主题(v0.3.0 起)

- **机制**:`<html data-ark-scheme="light|dark">` + CSS tokens 整体翻转(`:root[data-ark-scheme="dark"]` 重定义 `--ark-*`),组件规则零字面量;暗色 = Ark 方案 A 原设定(近黑舞台 `#080a0b` + 纸白文字 + 青 `#18d1ff` 信号),徽章三态/主按钮在暗下反转;**终端面板 token 除外(两主题恒暗)**
- **切换**:dock 末端太阳/月亮按钮(`aria-label="切换亮暗主题"`,40px 命中区);`toggleScheme` 用 **`document.startViewTransition`**(Chromium 111+ Document 接口——不要写成 `documentElement.startViewTransition`,那是 147+ 的元素级变体)包裹属性切换,以按钮为圆心的圆形揭示动效(`::view-transition-new(root)` clip-path circle 0.5s);`prefers-reduced-motion` 或 API 不可用时即时切换
- **持久化**:`localStorage['dd_scheme']`;`index.html` head 内联脚本在首帧前恢复,防闪白
- 简报与审查记录:`docs/theme-toggle-brief.md`

## 文件浏览对话框(v0.4.2 起)

- **机制**:tauri-plugin-dialog 插件(Cargo + lib.rs 注册 + capabilities `dialog:default`),前端经 `window.__TAURI__.dialog.open`(withGlobalTauri 暴露 `__TAURI__.dialog`);封装为 `AppBus.pickPath({ directory, filters, title })`,取消/组件缺失返回 null(缺失时 toast 提示)
- **三处入口**:服务器表单·私钥路径(选文件);项目表单·导入 compose(选 yml/yaml,回填后派发 input 事件触发与手输一致的解析联动);项目文件映射行·本地路径(按该行「目录」勾选动态选目录/文件)
- **记忆起点**:模块级 `lastPickDir` 记录上次所选路径的父目录,作为下次对话框 defaultPath
- **样式**:输入框右侧「浏览」小按钮(`.input-btn-row` flex 行),ark 双主题自动适配
- 简报与实现记录:`docs/theme-toggle-brief.md` 同目录惯例;插件权限如需收窄可用 `dialog:allow-open` 替代 `dialog:default`
