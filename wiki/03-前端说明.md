# 03 — 前端说明(ui/)

原生 HTML/CSS/JS,**无框架、无打包器、无 npm 运行时依赖**。`ui/` 目录即 Tauri 的 frontendDist,构建时整体内嵌进 exe。通过 `window.__TAURI__.core.invoke` 调后端(因 tauri.conf.json 设了 `app.withGlobalTauri: true`)。

## 页面结构(index.html,320 行)

单页应用:顶部黑色 dock 导航(4 项:`01 环境检测 / 02 镜像列表 / 03 服务器管理 / 04 部署向导`)+ 4 个 `<section data-page>`。默认显示检测页。导航顺序即使用闸门顺序。

## JS 模块与全局约定

### app.js(217 行)— 全局基础设施

| 成员 | 说明 |
|---|---|
| `window.showPage(name)` | 切换 section;`LOCKED_PAGES = ['images','deploy']` 在 `AppState.hostOk=false` 时拦截并灰置导航(截获后**不派发** pagechange);切页成功后 `window.dispatchEvent(new CustomEvent('pagechange'))`;新 section 触发 clip-path 揭示动画 |
| `window.AppState` | `{ hostOk: bool }`,读写镜像到 `localStorage['dd_hostOk']`(defineProperty 拦截) |
| `window.AppBus` | `{ invoke(cmd,args), on(event,cb) }`——invoke/listen 的封装,带 `__TAURI__` 缺失防护;**前端一律经 AppBus 调用** |
| `toast(msg)` | 右下角墨底纸白条,2.5s 自动消失 |
| `copyText(text)` | clipboard API + execCommand 回退 |

### check.js(396 行)— 01 环境检测页

加载即 `host_check()` 渲染 5 行清单(Docker 已安装 / 守护进程运行中 / compose 可用 / 磁盘 / 架构展示行);未通过项给一键启动(`start_docker`,失败后 5s 轮询重查)与可复制命令(`winget install Docker.DockerDesktop`、`Start-Service com.docker.service`);全部通过 → 斜切"环境就绪 READY"水印条 + `AppState.hostOk=true` 解锁导航。磁盘阈值 `DISK_MIN_GB = 2`(前端常量)。

### images.js(268 行)— 02 镜像列表页

`list_images` 表格(仓库/TAG/大小/创建时间/操作),搜索即时过滤,`formatBytes` 1024 进制;`<none>` 悬空镜像灰显且**不进部署按钮可用范围**;「部署」按钮设 `window.__pendingDeployImage = {repository, tag}` 后跳部署页;仅首次进入自动加载,手动刷新可用。

### servers.js(1,709 行)— 03 服务器管理页

- 服务器卡片 CRUD:认证方式 Key/Password 单选(密码框留空=沿用已存密文;输入新密码→`encrypt_password` 后存 `password_enc`);「测试连接」「环境检测」走 `test_server`/`server_env_check`;「一键安装 Docker」(自绘确认条,`install_server_docker`,输出进日志终端)、「创建远程目录」(`create_remote_dir`)
- 部署项目 CRUD:手工建项目 / **导入 compose 文件**(路径输入 → `preview_compose` 预览表 → 名称预填文件名 → 保存时 `import_compose` 副本落盘并入配置);文件映射行编辑(local/remote/is_dir)
- 删除:内联二次确认(3s 恢复);保存一律"新鲜 `get_config` → 就地改字段 → `save_config_cmd` 全量写回"(防覆盖 service_overrides 等表单外字段——曾有回归,已修并有冒烟测试)
- **保存失败强化通道**(v0.4.1):校验/失败双通道提示(内联错误框滚动到可视区 + toast);缺项聚合提示(如「请填写:名称、主机地址」);保存中按钮禁用显示「保存中…」;**保存成功后自动发起一次「测试连接」**,结果显示在卡片上
- **路径浏览按钮**(v0.4.2):私钥路径、导入 compose、文件映射行本地路径,均可点「浏览」调起系统文件/目录对话框(详见文末「文件浏览对话框」)
- **清理优化按钮**(v0.4.0):自绘确认条 → `prune_server` → 输出进 server-log 终端;与检测/安装互斥
- **项目表单生产字段**(v0.4.0):健康检查等待秒数(0=关闭)、pre/post-deploy 命令(配 4 个预设 chips:MySQL/PG 全库备份、悬空镜像清理、发布日志——点击插入可编辑,不默认加载)、完成通知 webhook URL
- `server-log` 监听模块级单次注册守卫(`logListenerBound`)

### deploy.js(1,432 行)— 04 部署向导页(双模式)

- **模式 tab**:「单镜像」/「整栈部署(compose)」;部署中禁切(`st.deploying || st.checking`);切模式 `resetRunView()` 清横幅/预检/日志/进度
- **单镜像模式**:镜像/服务器/项目三下拉 + 打日期 tag 勾选;进入页面若 `__pendingDeployImage` 存在则预填(用后置 null);开始 → `server_env_check` 预检(5 徽章,未过阻断+跳转按钮)→ `deploy(req)`(req snake_case);进度 5 节点 TAG/PACK/UPLOAD/SYNC/APPLY
- **整栈模式**:项目下拉 → `parse_compose` → 服务分类表(服务/镜像/匹配徽章三态/mode 切换按钮,has_build 的 Local 标「build」);errors 非空阻断;「保存为默认分类」→ 更新 project.service_overrides → save_config_cmd;开始 → `deploy_stack(req)`;进度 6 节点 CONFIRM/PACK/UPLOAD/LOAD/PULL/UP
- **事件处理**:deploy-progress 驱动节点状态(纯函数 renderProgress,幂等);deploy-log 追加日志(上限 2000 行丢最旧;接近底部才自动滚底);deploy-done 三态横幅(成功绿斜切条/失败墨底/取消黄条,message==="部署已取消" 识别取消);取消按钮 → `cancel_deploy` + "将在当前步骤结束后生效" toast
- 事件监听 `listenersBound` 模块级守卫,单次注册

## 设计语言(ark-light,style.css 1,145 行)

重构简报见 `docs/ui-redesign-brief-ark-light.md`,实施要点:

- **Tokens**(:root):`--ark-ink #080a0b`(墨)/ `--ark-paper #f4f6f6`(纸白主表面)/ `--ark-signal #18d1ff`(青,仅状态/激活/主操作)/ `--ark-signal-dim` / `--ark-ok #c8eb21`(仅成功徽章底)/ `--ark-warn #ffd23f`;radius 0;双色纪律(不用红,失败=墨底白字)
- **壳**:顶部黑色 dock 导航(索引数字 01-04 + 中文标签,激活=青字+青色下条);纸白舞台;每页页首超大 condensed 编号 + 中英双语标题
- **徽章三态**:`.badge-ok`(signal-dim 底)/`.badge-warn`(琥珀底)/`.badge-fail`(ink 底白字),配内联 SVG symbol(✓/×/▸,`<use>` 引用)——**禁 emoji、禁新增颜色字面量(只用 var(--ark-*))**
- **日志/终端**:`--ark-ink` 墨黑面板(全页唯一深色块),mono,左缘 4px 青条
- **动效**:切页 clip-path reveal 300ms;部署进行中节点 pulse 1.8s;`@media (prefers-reduced-motion: reduce)` 全归零;`@media (max-width:900px)` dock 转横向条
- **防 XSS 纪律**:所有动态数据 `createElement`/`textContent`,innerHTML 仅存在于注释(有审查 grep 验证)

## 前端硬约束(改动前必读)

1. 所有 invoke/事件字段 **snake_case**(见 [04-契约参考.md](04-契约参考.md)),invoke 参数名本身 camelCase
2. `document.getElementById` 的每个 id 必须在 index.html 存在(动态 id 模式:`check-*`、`deploy-step-1..6`、`srvf-*`、`prjf-*`)
3. 部署进行中不得再次发起 deploy(后端全局单取消标志,二次 deploy 会重置它)
4. 保存配置一律"新鲜 get_config → 就地改字段 → 全量写回",禁止用旧快照整对象替换
5. 事件监听用模块级守卫保证单次注册
6. 不引框架/打包器;不新增颜色字面量;不引入 emoji 图标

## 亮暗双主题(v0.3.0 起)

- **机制**:`<html data-ark-scheme="light|dark">` + CSS tokens 整体翻转(`:root[data-ark-scheme="dark"]` 重定义 `--ark-*`),组件规则零字面量;暗色 = Ark 方案 A 原设定(近黑舞台 `#080a0b` + 纸白文字 + 青 `#18d1ff` 信号),徽章三态/主按钮在暗下反转
- **切换**:dock 右端太阳/月亮按钮(`aria-label="切换亮暗主题"`,40px 命中区);`toggleScheme` 用 **`document.startViewTransition`**(Chromium 111+ Document 接口——不要写成 `documentElement.startViewTransition`,那是 147+ 的元素级变体)包裹属性切换,以按钮为圆心的圆形揭示动效(`::view-transition-new(root)` clip-path circle 0.5s);`prefers-reduced-motion` 或 API 不可用时即时切换
- **持久化**:`localStorage['dd_scheme']`;`index.html` head 内联脚本在首帧前恢复,防闪白
- 简报与审查记录:`docs/theme-toggle-brief.md`

## 文件浏览对话框(v0.4.2 起)

- **机制**:tauri-plugin-dialog 插件(Cargo + lib.rs 注册 + capabilities `dialog:default`),前端经 `window.__TAURI__.dialog.open`(withGlobalTauri 暴露 `__TAURI__.dialog`);封装为 `AppBus.pickPath({ directory, filters, title })`,取消/组件缺失返回 null(缺失时 toast 提示)
- **三处入口**:服务器表单·私钥路径(选文件);项目表单·导入 compose(选 yml/yaml,回填后派发 input 事件触发与手输一致的解析联动);项目文件映射行·本地路径(按该行「目录」勾选动态选目录/文件)
- **记忆起点**:模块级 `lastPickDir` 记录上次所选路径的父目录,作为下次对话框 defaultPath
- **样式**:输入框右侧「浏览」小按钮(`.input-btn-row` flex 行),ark 双主题自动适配
- 简报与实现记录:`docs/theme-toggle-brief.md` 同目录惯例;插件权限如需收窄可用 `dialog:allow-open` 替代 `dialog:default`

## 部署页生产加固元素(v0.4.0+)

- **部署预览**(整栈面板,独立按钮):`preview_stack_changes` → 五态徽章表(重建=warn / 新建=ok / 不变=info / 拉取=ok / 缺失=fail;errors 墨线框)。**独立功能,不接入开始部署流程**
- **部署历史**(折叠面板):`get_history` 渲染(时间 / 模式徽章 / 项目@服务器 / 镜像截断 / 结果徽章 / 耗时),最新在前,上限 50 条;pagechange + deploy-done 双触发刷新
- 失败提示走全表单统一的强化通道(见 servers.js 小节)
