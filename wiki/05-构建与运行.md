# 05 — 构建与运行

## 环境要求

| 组件 | 版本/说明 |
|---|---|
| Windows 10/11 x86_64 | 目标平台(仅 Windows 优先;DPAPI/CREATE_NO_WINDOW 等平台相关) |
| Rust stable(MSVC) | 本机装在 `D:\rust\`(环境变量 `RUSTUP_HOME=D:\rust\rustup`、`CARGO_HOME=D:\rust\cargo`,PATH 含 `D:\rust\cargo\bin`);MSVC Build Tools 在 `D:\rust\BuildTools` |
| Node.js + npm | 仅用于 @tauri-apps/cli(devDependency,无运行时依赖) |
| Docker Desktop | 本机要部署镜像就需要;应用检测不到时给出一键启动/安装指引 |
| 网络代理 | crate/npm 下载走 `https_proxy=http://127.0.0.1:7890`(本机 Clash;按需调整) |

## 常用命令

```bash
cd /d/Github-repositories/docker-deploy-ssh

# 开发(编译 debug 并启动应用;无 dev server,直接加载 ui/)
npm run tauri dev

# 测试(纯函数单测;真机测试 #[ignore] 需加 -- --ignored)
cd src-tauri && cargo test
cd src-tauri && cargo test docker:: -- --ignored   # 需本机 Docker 运行中

# 发布构建(产物见下;release 编译增量约 0.5-3 分钟)
npm run tauri build
```

注意:**不要直接运行 `src-tauri/target/debug/app.exe`**——debug 构建内嵌的是 dev 地址,脱离 `tauri dev` 会报 127.0.0.1 拒绝连接。要看成品直接跑 release exe 或装 NSIS 包。

## 构建产物

```
src-tauri/target/release/app.exe                                    # 主程序 ~7.9MB
src-tauri/target/release/bundle/nsis/DockerDeploy SSH_0.1.0_x64-setup.exe  # 安装包 ~2.3MB
```

- 打包目标:NSIS,语言 SimpChinese,per-user 安装
- `[profile.release]`:strip=true / lto=true / codegen-units=1 / opt-level="s"(体积优先)
- 版本号在 `src-tauri/tauri.conf.json` 的 `version`(当前 0.1.0);git tag 惯例 `v0.1.0`

## 安装与运行期布局

```
<安装目录>/                       # NSIS 默认 per-user 目录(config/ 需可写)
├── DockerDeploy SSH.exe
├── config/
│   ├── servers.json              # 服务器列表(auth.password_enc 为 DPAPI 密文)
│   ├── projects.json             # 部署项目(含 service_overrides / 钩子 / 健康检查 / webhook)
│   ├── deployments.json          # 部署历史(上限 200 条)
│   └── stacks/<uuid>/            # 导入的 compose 副本(docker-compose.yml[+ .env][+ override] + origin.json)
└── logs/app.log                  # 运行日志(Info 级,自动轮转)——排障先看这里
```

- 配置便携:整个目录可拷贝迁移(**跨机器迁移后 DPAPI 密文不可解**——密码需重录)
- `DD_CONFIG_DIR` 环境变量可重定向配置根目录(测试用途)
- debug 构建同理在 `src-tauri/target/debug/` 下生成 config/ 与 logs/

## 应用自身的前置条件(内置检测)

| 宿主机 | 服务器(SSH 探测) |
|---|---|
| Docker 已安装(`docker --version`) | docker 命令(缺→一键安装:get-docker.sh,1800s) |
| 守护进程运行中(`docker info`;缺→一键启动,60s 轮询) | docker compose 插件 |
| docker compose 插件 | gzip |
| 临时目录盘剩余空间(前端阈值 2GB) | remote_dir 存在(缺→一键创建) |
| 架构展示(仅信息) | 磁盘剩余(df -PBG;BusyBox 系统拿不到,记 0) |

宿主机未通过 → 镜像/部署页锁定;服务器检测未通过 → 该服务器不可作为部署目标(部署向导会拦)。

## 故障排查速查

| 现象 | 先看 |
|---|---|
| 部署失败 | `logs/app.log` 中 deploy-log 对应时间段;失败步骤名在 deploy-done message 与日志尾部 |
| 服务器检测卡住后超时 | 网络可达但 SSH 通道停滞;确认端口/防火墙 |
| 配置丢失/字段被重置 | 是否用了旧快照整对象替换保存(前端约定:新鲜 get_config 就地改) |
| release 下看不到 stdout | 正常——release 无控制台;看 logs/app.log |
| 密码报"解密失败" | 密文绑定同用户同机器;换机器/用户需重录密码 |
